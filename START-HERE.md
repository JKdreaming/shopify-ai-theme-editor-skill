# Use the Shopify AI editor setup skill

1. Unzip this folder.
2. Open your preferred AI coding tool. Use a workspace with local file and terminal access for the direct connection workflow.
3. Attach or open `SKILL.md`, or install this folder using the harness's normal skill controls if it supports native skills.
4. Send this instruction:

> Follow SKILL.md to connect my AI editor to Shopify. Ask which folder I want to use, then create SHOPIFY-AI-SETUP.md inside that folder and guide me through the setup. Work against a draft theme. Keep credentials private and wait for my release approval before publishing.

5. Choose the project folder when asked. The assistant creates your setup instruction document there and downloads the theme into a separate `theme/` subfolder.

The instructions are designed for major AI harnesses and LLMs, including Claude, ChatGPT/Codex, Gemini, DeepSeek, and more. Native installation differs by harness. A chat-only interface can explain the steps; editing and uploading require file tools, terminal tools, network access, and authorized Shopify access.

No Shopify or AI API key is included in this download. The skill explains account login, optional credential creation, private entry, verification, and cleanup. It does not automatically publish your theme.
