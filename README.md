# Shopify AI Theme Editor Setup Skill

Connect Claude Code, ChatGPT / Codex, Gemini CLI, DeepSeek, and other capable AI coding tools to Shopify themes. This skill guides authentication, creates a setup instruction file in your chosen folder, downloads a theme, and walks through preview and draft review.

## Get started

Download this repository as a ZIP, extract it, and open `SKILL.md` in your AI coding tool. Follow [START-HERE.md](START-HERE.md) for the prompt and setup instructions. Your assistant will ask you to choose a project folder and create `SHOPIFY-AI-SETUP.md` there.

Direct editing requires a coding harness with file, terminal, and network access, plus authorized Shopify access. Native skill installation varies by tool. Keep credentials private and review the draft before publishing.

The template is in [references/SHOPIFY-AI-SETUP.template.md](references/SHOPIFY-AI-SETUP.template.md). No credentials are included.
